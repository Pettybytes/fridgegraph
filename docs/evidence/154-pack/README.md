## State labelling

All four compositions are **mock states**, not live authorization proof:

- **populated** — illustrative authorized content for the selected child;
- **empty** — illustrative "nothing scheduled" result;
- **refused** — illustrative "not available" result for a caller without permission or the demo guide.

No screenshot demonstrates that a real caller was authorized, and none was produced from a live API
response for live content.

## Choices

- No reference-image support was verified for this endpoint, so the pack avoids introducing
  recognizable faces: candids are behind, distant or motion-blurred, and the Navy keepsake is turned
  away with a softened face.
- Pets, holidays, service history and celebrations are creative fixture choices recorded in the
  manifest, not facts inferred from names, ethnicity or relationships.
- Shared artwork conveys no permissions. Co-parent layouts are person-scoped; a caregiver in several
  families sees only the selected child's pack; the demo guide gets art but no live content; a new
  family starts empty and inherits nothing.
